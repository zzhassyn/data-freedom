# Архитектура

Стек: Python 3.10+, FastAPI, Pydantic v2, httpx, sqlite3. Один процесс uvicorn; отдельные сервисы не нужны.

- `app/main.py` — приложение, жизненный цикл, CORS, единая форма ошибок, health и раздача `../web`.
- `app/models.py` — общие типы ML и HTTP; `settings.py` — окружение; `db.py` — SQLite, транзакции, текущие готовые оценки.
- `app/conversations.py` — импорт/валидация/поиск, история, потоковый аудиопрокси.
- `app/checklists.py`, `app/seed/checklist_v1.json`, `app/apply.py` — неизменяемые версии, дословный сид, хэши и сравнение.
- `app/scoring.py` — единственный расчёт баллов через Decimal; им пользуются очередь, апелляции, точность и выгрузка.
- `app/evaluations.py` — постоянные задачи, приоритетная asyncio-очередь, ограничение параллельности, сохранение каждого критерия, восстановление, reuse/retry.
- `app/appeals.py` — транзакционные решения с сохранением исходного ответа и полного пересчёта.
- `app/stats.py` — сводка, CSV-разметка, сравнение исходных ответов модели с gold.
- `app/extras.py`, `app/operators.py`, `app/export.py` — ИИ-кэш с проверкой версии источника, операторы, выгрузки.
- `app/judge/`, `app/ai/`, `app/llm_switch.py` — провайдеры модели, их выбор из настроек и явная подстановка зависимостей для тестов.

SQLite по умолчанию `data/cqa.sqlite`, режим WAL, внешние ключи, уникальная активная версия и открытая апелляция на пару оценка/критерий. JSON хранится в TEXT; идентификаторы постоянны. Сетевые ожидания не держат транзакцию. Оценка хранит снимок входного диалога, чтобы изменение источника не меняло смысл старых доказательств.

Запуск из `backend`: `uvicorn app.main:app --port 8000`. Проверки: `pytest -q`. Инструкции и переменные окружения — `README.md`, наблюдения проверок — `TESTING.md`.
