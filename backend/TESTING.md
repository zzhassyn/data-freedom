Проверены откат после вставки расходов, смена идентичности до вызова, потеря аренды до и после HTTP, таймаут без повторной отправки и восстановление после отмены в режимах standalone и worker. Неизвестная стоимость остаётся обозначенной `usageIncomplete:true`, в том числе после успешного ручного повтора; известная сумма сохраняется отдельно.

Десять ресурсов инструкций сверены с выбранной зафиксированной V3: system и semantic-policy побайтово, восемь уточнений — с соответствующей строкой JSON, развёрнутой в UTF-8 файл с финальным LF. Опрос worker выбирает только ожидающие оценки; STT-опрос выбирает только ожидающие задания, а список заданий не загружает готовые тексты расшифровок. Тесты запрещают запись из проверяемых путей чтения. Защита транзакций нативного libSQL, аренда worker, проверки поколений STT и поведение платных вызовов сохранены.

Отпечатки всех таблиц совпали точно; исключено только меняющееся значение аренды worker. Новых строк и изменений сохранённых данных не появилось.
