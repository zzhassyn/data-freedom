## Как считаем

- Берём последнюю созданную оценку по версии 1 для текущего транскрипта. Если она завершилась ошибкой или ещё идёт, старый готовый результат не подставляется.
- Сравниваем исходный ответ модели до решения по апелляции. Для итогового балла также используем исходные ответы.
- Совпадение — доля точных совпадений среди пар «явная ручная метка + допустимый готовый ответ модели». Для шкалы сравниваются исходные ступени, а не баллы после взвешивания. «Не применимо» — отдельный ответ.
- Пустая ручная метка не считается ответом и не заменяется ответом модели. Частичная разметка участвует в сравнении отдельных критериев, но не в средней разнице итогов.
- Для средней разницы итогов нужны все восемь ручных ответов. Оба итога пересчитываются по версии 1 с перераспределением веса неприменимых критериев; затем берётся средняя абсолютная разница.
- Повторные пары «обращение + критерий» отклоняются. Ошибочные значения, неизвестные ID и неполнота отдельно отражаются при проверке входного JSON.

Экран сравнения: `#/lab/accuracy`. CSV содержит столбцы `conversation_id,criterion_id,answer,note`. После готовности ручного файла остаётся проверить его загрузку в браузере и зафиксировать источник данных вместе с итоговыми замерами.
